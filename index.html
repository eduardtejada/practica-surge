Flujo del Pipeline de CI/CD

1.

Commit y Push Local

Los cambios en el codigo fuente son confirmados y enviados a la rama principal en GitHub.

2.

Disparo de GitHub Actions

El evento de push activa automaticamente el flujo de trabajo configurado en .github/workflows/main.yaml.

3.

Despliegue Seguro en Surge.sh

Se utiliza el token de autenticacion guardado de forma segura en los Secrets del repositorio para publicar el sitio.
